# SIST — スプレッドシートで更新する社内リンク集（GAS版）

添付HTMLの75件のリンク、5セクション、10小分類、CSS、配色、カード配置、アイコン、改行、ツールチップ、検索、右下の「過去リンク」を移行しました。リンクを別タブで開くようにして、GASのiframe内でも遷移できる構成にしています。

**ソース:** [Code.gs](apps-script/Code.gs) ／ [Index.html](apps-script/Index.html)

運用時はスプレッドシートのセルを編集するだけです。変更はページを**再読み込み**すると反映されます。シート編集のたびにGASを再デプロイする必要はありません。開いたままのページへの自動配信は行いません。

## 初回導入

1. リンク管理用のGoogleスプレッドシートを新規作成します。
2. そのシートで **拡張機能 → Apps Script** を開きます。
3. エディタに次の2ファイルを作成し、内容をコピーします。既存のプロジェクトを使う場合は、同名関数やファイルと重複しないことを確認してください。以前の版の `SeedData.gs` がある場合は削除してください。

   | ファイル | 種類 | 内容 |
   | --- | --- | --- |
   | `Code.gs` | スクリプト | `apps-script/Code.gs` |
   | `Index.html` | HTML（作成時の名前は `Index`） | 最初に提供されたHTML全文をそのまま使用（`apps-script/Index.html`） |

4. ファイルを保存し、関数選択で **`setup`** を選んで一度実行し、Googleの権限確認を承認します。管理用スプレッドシートに「リンク」「設定」の2シートができ、元HTMLから読み取った75件が入ります。対象シートIDはスクリプトプロパティ `LINKS_SPREADSHEET_ID` に自動保存されます。コード内へのID記入は不要です。実行ログに **「診断OK: 75件のリンク、5セクションを読み込めました。」と「初期設定完了」** が出れば、読み込みまで確認できています。既存データを編集済みなら件数は異なります。
5. **デプロイ → 新しいデプロイ → ウェブアプリ** を選びます。「次のユーザーとして実行」はシートを読み取れる所有者にし、アクセスできるユーザーは利用する組織の範囲に設定してください。元データは社内リンクのため、社外への一般公開は想定していません。
6. 発行されたウェブアプリURLを開きます。リンク先の各Googleドキュメント等には、それぞれのアクセス権が必要です。

新規のGASプロジェクトではマニフェストが自動作成され、権限もコードから推定されるため、`appsscript.json` の手動設定は不要です。同梱ファイルは権限を明示する場合の参考用です。

実行ボタン横の関数選択欄では **`setup`**、診断時は **`diagnose`** を選びます。表示されない場合はコードを保存し、エディタを再読み込みしてください。末尾に `_` がある関数は内部処理用で、直接選択する必要はありません。

`Index.html` はレイアウトの原本として保存します。画面表示時にはGSがシートからカードを生成してHTMLのリンク領域を置き換えるため、元HTMLのリンクがシートの変更を上書きすることはありません。初期登録後はリンクをHTMLで編集せず、シートで管理してください。

スプレッドシートを開き直すと「リンク集 → 初期設定（既存データは保持）」メニューからも実行できます。初期設定を再実行しても、データのあるシートは上書きしません。削除した行や変更済みのURLが初期値に戻ることもありません。

## リンクの更新

「リンク」シートは1行が1カードです。1行目の見出しと列順は変更しないでください。

| 列 | 項目 | 編集方法 |
| --- | --- | --- |
| A | セクションID | 分類の識別子。例: `section-soumu`。半角英字で始め、英数字・`-`・`_`を使用。同じ分類は同じIDにします。 |
| B | セクション名 | 例: 庶務関連申請。同じIDの行は同じ名前にします。 |
| C | セクションアイコン | 例: `clipboard`、`briefcase`。同じIDの行は同じ値にします。 |
| D | 小分類 | 例: 申請、ツール、マニュアル。空欄ならセクション直下にカードが並びます。 |
| E | リンク名 | カードの表示名。セル内改行はそのままカードの改行になります。 |
| F | URL | `https://` または `http://` から始まるURL。メール作成用Gmailの長いURLもそのまま保存できます。 |
| G | アイコン | Featherのアイコン名。例: `file-text`、`mail`、`download`。空欄なら `link`。 |
| H | 説明 | マウスを重ねたときのツールチップ。空欄なら表示しません。 |
| I | 表示順 | 小さい数値から表示。同値は行順。空欄はその行番号を使います。 |
| J | 表示 | チェックあり／`TRUE`で表示。チェックなし／`FALSE`で非表示。空欄は表示扱いです。 |

- **URL変更:** F列を編集して、ウェブアプリを再読み込みします。
- **追加:** 同じ分類の行をコピーして、E〜J列を編集します。新しい分類はA〜D列も変更します。
- **削除:** 行を削除します。一時的に隠すときはJ列のチェックを外します。
- **並び替え:** I列を編集します。セクションと小分類も、それぞれ最初に現れる表示対象リンクの順序で並びます。

「表示」は画面に載せるかどうかの設定で、アクセス権の設定ではありません。管理シートの編集権限は管理担当者に付与してください。URLは文字列としてセルに入力します。`HYPERLINK`関数や表示名だけのスマートチップではなく、URLそのものをF列に保存してください。

## タイトル・過去リンク

「設定」シートの「値」列を編集します。

| 項目 | 用途 |
| --- | --- |
| ページタイトル | 画面上部の「各種リンク集」 |
| ブラウザータイトル | ブラウザータブの「社内リンク集」 |
| 過去リンク名 | 右下の固定リンクの表示名 |
| 過去リンクURL | 右下の固定リンクのURL |
| 過去リンク表示 | `TRUE`で表示、`FALSE`で非表示。URLが空欄でも非表示。 |

## 読み込めない場合

利用者には読み込みエラーを表示し、詳しい原因はApps Scriptの「実行数」から実行ログで確認できます。

- **「初期設定が完了していません」と表示される場合:** 管理用スプレッドシートから開いたエディタで `setup` を実行し、権限を承認します。これは設定用シートの場所を登録する操作で、データのある既存シートは上書きしません。成功したらウェブアプリを再読み込みします。
- **「リンク集を読み込めませんでした」と表示される場合:** エディタで `diagnose` を実行します。失敗すれば、欠落シート、不正な見出し、URLの行番号などの具体的なエラーがエディタに表示されます。成功すればリンク件数とセクション数を表示します。診断はシートを変更せず、シートIDやリンク先URLはログに出しません。
- **コードを更新した場合:** GitHubの最新版 `Code.gs` をGASに反映して保存し、「デプロイ → デプロイを管理 → 編集 → 新しいバージョン → デプロイ」で公開中の版を更新します。Google上のコードはGitHubへのpushだけでは更新されません。
- 初回はスプレッドシートに紐づくエディタで `setup` を実行してください。
- 「リンク」「設定」シートの名前、列見出し、セクションID・名前の統一、URL、表示順を確認してください。表示対象行の不正なデータはエラーになります。下書きの行はJ列を `FALSE` にしておけます。
- 実行ユーザーが管理シートを読めること、ウェブアプリの公開範囲を確認してください。
- スクリプトの修正時は、デプロイの管理から新しいバージョンに更新します。シートの値の変更だけなら不要です。

## 開発環境と検証

Node.js 20以上を使います。外部npm依存パッケージのインストールは不要です。

```sh
cd /workspace/SIST
npm test
```

元HTMLとの全リンク・CSS比較、シート更新、並び替え、非表示、初期設定の再実行、エラー表示、HTMLのエスケープ、検索をテストします。`tests/fixtures/original.html` は提供された元HTMLです。

```sh
npm run preview
```

ローカルの確認用サーバーをポート3000で起動します。初期データを使った表示専用のサンプルで、Googleスプレッドシートには接続しません。`PORT`でポートを変更できます。停止はCtrl+Cです。

元HTMLと同様、ブラウザーが `cdn.tailwindcss.com` と `unpkg.com` から表示用ライブラリを読み込みます。クラウド環境でこれらへの通信を制限している場合、環境設定の許可ドメインに追加してください。

ローカルテストはGoogleサービスの代替オブジェクトを使います。Google上での権限承認、HtmlService固有の動作、実シートからの読み込みはデプロイ後の確認が必要です。初回導入後、①75件の表示、②F列を変更して再読み込み、③J列のチェックを外して非表示、④検索と別タブ遷移、を確認してください。クラウド環境からGoogleへのデプロイは実行していません。
